Test whether the MELK-OA10WCT equalizer modes respond to a phone-supplied signal by lighting separate LED sections. One lamp, continuous external signal tests, no firmware changes.

3 · Feed an audio-level test

This sends the documented music-reactive RGB frame (flag 0x20), which differs from the ordinary whole-lamp RGB frame (flag 0x10). It may be ignored or act on the whole lamp; we're testing whether EQ mode interprets it as section data.

4 · Continuous external-control tests

Unlike one-shot frames, these send changing RGB payloads about 8 times per second, for a limited period. First test the deterministic pulse without music; then try the phone microphone. This does not assume that flag 0x20 addresses individual LEDs.

For both pulse tests: lights alternate red channel level 0 ↔ 255 every 0.5 seconds, using 8 BLE writes/second. Compare whether 0x20 follows the same square wave as ordinary RGB (0x10), changes zones, or gets ignored.

Phone input level—

Use count 30. For an isolated test, start Energetic II, turn the lamp’s internal microphone OFF, then run the pulse. If mic OFF also ends the mode, record that instead of assuming it worked.

The webpage requests microphone permission only when you start the live test. It does not record, upload, or save audio. The audio may include any sound the phone microphone hears, including your voice and music played through a nearby speaker. Each stream has a hard duration limit.
