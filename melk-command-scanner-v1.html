2 · Scan configuration

Candidate format: 7E 07 XX YY FF 00 00 10 EF. Only XX and YY vary. This is a hypothesis, not a confirmed section-control format.

150 ms minimum. 65,536 commands take about 9.1 hours at 500 ms, plus BLE overhead. The phone must remain awake and the page open.

Index = (byte 3 × 256) + byte 4. Example: index 1285 = 05 05. Set a smaller range to test subsets.
